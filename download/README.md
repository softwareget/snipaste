# Snipaste

比Super+PrtSc强百倍，**万能截图工具**！！

## 下载

**[点击去Snipaste官网下载](https://www.snipaste.com/)**

> *请往下滑，找到“Download For Free”（也叫Download Portable）。*

*F1截图哦！*

## 使用

运行Snipaste.exe（可以在.zip里找到）后，请点电脑**右下方**的“^”，打开SNIPASTE图标，就可以了！
